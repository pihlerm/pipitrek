PEC Analysis Instructions

To perform PEC (periodic error correction) analysis, do the following steps:

  1. Set up the telescope, polar align. Do not yet start telescope!
  2. Point the telescope to near astronomical equator and near vertical. Put pier on E side.
  3. Manually turn the RA worm gear so that the marking is at zero.
  4. Start the telescope. Perform camera orientation calibration (Calibrate button on Guider tab).
  5. Select a single star to track for PEC analysis. The star should be bright and isolated near center, but not too bright.
  6. Start the PEC analysis by clicking the Start button.
  7. Current PEC table will be automatically downloaded from arduino.
  8. PEC table length is fixed to 51 entries; offset + 50 segments.
  9. Analysis will perform one full turn of the main worm gear (approx 10 minutes).
  10. During the analysis, avoid touching the telescope or changing its orientation. Tracking must be ON, but guiding must remain OFF.
  11. Once data capture is complete, it will automatically generate PEC table.
  12. If all is OK, upload the calculated corrections to the PEC table to firmware on the Arduino PipiTrek.
  13. Iteratively repeat the process until the PEC error is minimized.
